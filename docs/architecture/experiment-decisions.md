# Experiment decisions and unfinished qualification

Recorded 2026-09-07 from the repository's retained trial receipts. This collects the experiments referred to in the final strengthening report, plus earlier component decisions that could otherwise be confused with them. It is not a fresh benchmark or an assessment of newer releases.

“Rejected experiments” was too broad. A failed requirement, an unconvincing replacement, an unfinished integration and an untested option have different meanings. None of these decisions permanently excludes a project.

## How to read plan completion

An evaluation can finish with a keep-current decision, but that does not finish an unimplemented integration or an unrun comparison. The full richer-memory candidate corpus, full challenger desktop parity, production VM/remote module and in-app ACP mode remain outstanding work if pursued. The plan's checked evaluation dispositions must not be used to claim those features shipped.

No new permanent exclusion or cancellation is created by this document. Revisit the recorded version/configuration and its specific blocker rather than starting from an assumption that the upstream project is unsuitable.
